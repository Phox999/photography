# 後台互動模擬

在專案根目錄執行 `node tools/admin-prototype/server.mjs`，開啟 http://127.0.0.1:4328 。需要既有 Node 24 與專案已安裝的 sharp，不需新增套件。

此獨立工具不屬於 Astro 的公開路由，沒有連接後台 API。讀取本機作品及縮圖，每個作品最多載入 36 張供操作驗證；正式內容不會改變。瀏覽器重新整理會重設全部模擬狀態。

可測試：作品搜尋／分類、新增作品、作品與照片拖曳排序、Alt + 左右鍵排序、勾選及 Shift 區間選取、全選、批次移動／移除、一步復原、單張檢視與方向鍵、獨立封面、資訊抽屜、加入本機照片、模擬發布，以及合作、檔期、回饋、網站內容及紀錄頁面。成效頁不產生虛構數據；資料操作僅為模擬。

圖示來源：Lucide 0.468.0，原始 SVG 取自 https://github.com/lucide-icons/lucide/tree/0.468.0/icons ，授權位於 icons/LICENSE。圖示為外部現成資產，未自行繪製。只有字型使用 Google Fonts，無網路時使用系統字型。

新 checkout 沒有本機原始作品照片時，會使用此次一併提交的前台設計素材作為示意相簿；不需上傳整個原始照片庫。
前台預覽啟動方式見 ../frontend-preview/README.md。
